# Schedule Composer

Chat with Claude about a Primavera P6 schedule and watch it change. Open an XER, ask for edits in plain English ("add a 10-day punch list after Final Clean", "shift MEP rough-in two weeks", "what's driving substantial completion?"), see the table and Gantt move as each tool call lands, then export the XER back to P6.

See `CLAUDE.md` for layout, run commands and engine notes, and `PROTOCOL.md` for the server/browser protocol.
